Variance Partitioning — Per-Feature Confound Analysis

How fitting 148–32,000 linear models and decomposing their variance tells the same story as PERMANOVA, feature by feature.

Prerequisites: Lesson 1 (shared variance, marginal vs sequential tests).

Why variance partitioning?

PERMANOVA answers: "How much of the overall distance between samples does each covariate explain?" It's a single number per modality.

Variance partitioning answers: "For each individual feature (probe, CpG, motif, bin), how much of its variance is explained by each covariate?" It gives you a distribution across features, not just one number.

The two methods use completely different machinery, but they should converge on the same story. When they do, you can trust the result.

Why this matters: PERMANOVA might miss a confound that affects only 5% of features very strongly (it gets diluted in the full distance matrix). Variance partitioning catches this — each feature contributes equally, so a 5% feature subset with strong confound signal won't be invisible.

How it works

For each feature (e.g., one methylation probe), fit:

$$feature \sim Tissue + Source + BCT + Sex$$

This is a standard linear model (ordinary least squares). The ANOVA table decomposes the total sum of squares into portions attributable to each term. Because the covariates are categorical, we use one-hot encoding: Tissue becomes 5 dummy variables (6 tissues minus 1 reference), Source becomes 3, BCT becomes 3, Sex becomes 1 — plus the intercept.

Type II sums of squares means each term's SS is computed after accounting for all other terms, but without interactions. This is analogous to the marginal (Type III) PERMANOVA — each term gets credit only for what it uniquely explains.

The fraction for Tissue is:

$$\frac{SS_{Tissue}}{SS_{Tissue} + SS_{Source} + SS_{BCT} + SS_{Sex}}$$

This is the fraction of model-explained variance that Tissue accounts for. (The remaining variance — not explained by any covariate — is the residual, which dominates for most features.)

The Tissue values align closely. The BCT values show the same rank order (Tissue > Source > BCT) but the VP mean is higher for BCT in some modalities. Why?

PERMANOVA operates on the PCA-reduced feature space (or the full feature space via Euclidean distances). The distance matrix is a single summary of all features jointly. BCT's tiny unique contribution across all features together is 0.018.

Variance partitioning averages per-feature fractions. If a few features are strongly driven by BCT, they pull the mean up — even though most features have zero BCT signal. The median BCT variance fraction is near zero for most modalities.

Why VP BCT looks higher than PERMANOVA BCT for FEM4: Some FEM4 features capture technical variation (sequencing depth, GC bias) that happens to correlate with tube type. PERMANOVA dilutes these across all 256 features; VP averages them feature-wise. The correct interpretation is: most features have negligible BCT signal, a small minority have detectable BCT signal, and PERMANOVA correctly tells you the overall impact is tiny.

The violin plot

Open output/diagnostic-protocol/varpart_FEM4_(256)_Full_(164).png — you'll see a violin plot with four violins (Tissue, Source, BCT, Sex). The Tissue violin is the widest at higher fractions; the BCT violin hugs zero. The red line at 0.10 is the materiality threshold used in the adjudication.

Why this matters

  • VP confirms PERMANOVA's conclusions at the per-feature level. Two completely different methods (distance-based permutation test vs per-feature OLS) tell the same story. This is converging evidence.
  • VP reveals feature-level structure. If a confound drives only a few features very strongly, VP will show it while PERMANOVA might not. In our case, neither shows BCT as a problem.
  • VP's BCT values are slightly inflated by a few outlier features. This is normal — and reinforces why the protocol uses four converging methods, not one.

Limitations

  • Linear model assumption. The relationship between a feature and covariates might be nonlinear. OLS only captures linear associations. If BCT had a complex nonlinear effect, VP might miss it — but PERMANOVA (distance-based) would catch it.
  • No interactions. The model is additive. A Tissue×BCT interaction (e.g., "BCT affects liver methylation differently than colon") would be absorbed into the residuals and missed by both VP and the simple PERMANOVA model.
  • Computational cost. 32,000 linear models × 164 samples takes ~60 seconds. Not prohibitive, but you wouldn't do it for every analysis.

Key takeaways

  1. VP = PERMANOVA at single-feature resolution. They use different math but converge on the same ranking: Tissue > Source > BCT.
  2. VP's BCT mean can be inflated by outlier features. Check the median or the full distribution, not just the mean.
  3. Converging evidence is powerful. When PERMANOVA, VP, classifier negative controls, and PCA all tell the same story, the conclusion is robust.
  4. VP is the method to use when you care about which features are confound-driven (e.g., to flag or remove them).

Check your understanding:

The VP mean for BCT in FEM4 is 0.087 — triple the PERMANOVA value (0.018). Does this mean PERMANOVA underestimated BCT?

No. PERMANOVA measures the unique contribution of BCT to the overall distance matrix — a single summary of all 256 features. VP averages per-feature fractions, which a small number of BCT-driven features can inflate. The two methods answer different questions:
  • PERMANOVA: "What fraction of total multivariate variance does BCT uniquely explain?"
  • VP: "For the average feature, what fraction of its model-explained variance comes from BCT?"
Both agree that Tissue dominates and BCT is minor. The exact number differs because the aggregation differs.
